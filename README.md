# Погода через OpenWeather

Небольшое консольное приложение на Python для получения текущей погоды в заданном городе или по координатам через [OpenWeather API](https://openweathermap.org/api).

## Возможности

- Поиск погоды по названию города (Geocoding API + Current Weather API).
- Поиск погоды по координатам (широта/долгота).
- Понятные сообщения об ошибках без трейсбеков (невалидный ключ, город не найден, сетевые сбои).
- Кэширование последнего успешного ответа в `weather_cache.json`. При сетевой ошибке предлагается вывести данные из кэша, если они моложе 3 часов.
- Ретраи с экспоненциальной паузой (1s, 2s, 4s) при HTTP 429 и временных сетевых ошибках.

## Требования

- Python 3.10+ (проверено на 3.13)
- Бесплатный API-ключ OpenWeather

## Установка

1. Клонируйте репозиторий и перейдите в его каталог.

2. Создайте и активируйте виртуальное окружение:

   **Windows (PowerShell):**
   ```powershell
   python -m venv .venv
   .\.venv\Scripts\Activate.ps1
   ```

   **Linux / macOS:**
   ```bash
   python3 -m venv .venv
   source .venv/bin/activate
   ```

3. Установите зависимости:

   ```bash
   pip install -r requirements.txt
   ```

4. Получите API-ключ на https://openweathermap.org/api и укажите его в файле `.env`:

   ```
   API_KEY=ваш_ключ_OpenWeather
   ```

   > Новому ключу может потребоваться до 10–60 минут на активацию.

## Как это работает

- `get_coordinates(city)` — обращается к Geocoding API (`limit=1`, `lang=ru`) и возвращает `(широта, долгота)`.
- `get_weather_by_coordinates(lat, lon)` — обращается к Current Weather API (`units=metric`, `lang=ru`) и возвращает словарь с погодой.
- `_request_json(...)` — общий HTTP-слой с таймаутом, ретраями и понятной обработкой ошибок (401, 404, 429 и сетевые сбои).
- `save_cache(...)` / `load_cache()` / `offer_cached_weather()` — работа с кэшем `weather_cache.json`.

## Обработка ошибок

| Ситуация | Сообщение |
| --- | --- |
| Ключ не задан/неверный | `Невалидный API-ключ (401)...` |
| Город не найден | `Город «...» не найден.` |
| Превышен лимит запросов | до 3 повторов с паузами 1s/2s/4s, затем понятная ошибка |
| Нет интернета / таймаут | сообщение + предложение вывести кэш (если моложе 3 часов) |

## Примечания

- Файл `.env` и `weather_cache.json` добавлены в `.gitignore` и не должны попадать в репозиторий.
- Кэш содержит метаданные `city`, `lat`, `lon`, `fetched_at` и сам ответ API.
- Значение `API_KEY` из файла `.env` имеет приоритет над системными переменными окружения (`load_dotenv(override=True)`).
